## Project Description
This project is a personal portfolio website built using HTML5. It introduces me, showcases my skills and projects, and provides a way for visitors to contact me. The website includes multiple pages and follows semantic HTML and accessibility best practices.

## Technologies Used
- HTML5
- Git and GitHub
- GitHub Pages
  
## Features
- Home page with a personal introduction and tagline
- About page with background, skills, and education
- Projects page showcasing at least three projects
- Contact page with a contact form and social media links
- Consistent navigation across all pages
- Semantic HTML structure
- Accessible images, links, and form labels
- Responsive layout for different screen sizes

## How to Run
1. Clone repository
2. Open `index.html` using the Live Server extension.

## Lessons Learned

I learned how to structure webpages using HTML5, create semantic layouts, build navigation links between multiple pages, and create accessible forms. I also learned how to use Git and GitHub to manage my project and deploy a website using GitHub Pages.

## Challenges Faced

I faced challenges with organizing the different pages, maintaining consistent navigation, and making the website accessible. I addressed these issues by using semantic HTML, and testing the pages in the browser.
